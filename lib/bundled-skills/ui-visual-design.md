# 界面视觉设计

适用于新做页面、改版、「做得好看一点」、配色字体间距不协调、明暗主题不一致这类问题。交互状态（提交中、失败、过期请求）看 `deep-ptc-frontend-design`；需要在浏览器里核对时加载 `deep-ptc-local-web-testing`。

## 先读已有的设计系统

- 项目里有设计变量、主题文件、组件库或 CLAUDE.md/AGENTS.md 里的约定时，全部沿用，只补空缺。优先级：用户的明确要求 → 项目已有系统 → 你的选择。
- 给 DSH 写插件界面时，颜色、圆角、阴影用宿主的 `--dsw-*` 变量并带兜底值，跟随宿主明暗，不另起一套主题色。宿主实际用了哪些变量，用 Cordis Inspect 或 DevTools 读出来再用。
- 独立项目没有现成系统时，先用一句话写下：给谁用、这个页面唯一的任务、想要的气质。再挑一个只属于这个题材的细节作为内容的一部分（真实单位、行业术语、该领域的版式习惯），而不是装饰。

## 定一套小而完整的变量

把决定写成变量放在样式最前面，后面的规则只引用变量。

- **颜色 4–6 个**：页面底色、表面色、正文/次要/弱化三级文字、分隔线、一个强调色。成功、警告、错误是语义色，单独定义，不算强调色。中性灰向强调色的色相轻微偏移，比纯灰显得有意图。
- **明暗两套同名变量**：浅色写在 `:root`，深色只重新赋值同一批变量（跟随 `prefers-color-scheme`，有显式切换时再按 `data-theme` 覆盖）。深色不是反色：降低大面积的亮度，阴影换成细边框，强调色调到在深底上同样清楚。
- **字体两种以内**：正文一种，标题或数据可选一种。中文栈写全（如 `"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui`）；数字列加 `font-variant-numeric: tabular-nums`。
- **字号阶梯固定**：如 12 / 13 / 14 / 16 / 20 / 24 / 32，正文行高 1.6–1.75，标题 1.25–1.35。一页里不要出现阶梯外的字号。
- **间距以 4 或 8 为基数**：同级元素用 flex/grid 的 `gap`，不靠每个元素各自的 margin。

## 层级与排版

- 一屏只有一个焦点：一个主按钮（实心），其余按钮用描边或文字样式。次要信息靠颜色变淡而不是缩到看不清（正文不小于 12px）。
- 重复的元素（卡片、列表行、标签）边缘、基线、内边距一致，同一种元素放在同样的位置。容器高度由内容决定；选列数时让最后一行不留孤零零的一格。
- 边框、底色、圆角、阴影都在说「这是一个独立对象」，按角色给，不要每块都套一样的卡片。
- 编号、眉题、分隔线要表达真实信息（例如确实有先后顺序才编号）。
- 长文本最多约 65 个字符宽；表格、代码、图在各自容器内横向滚动，页面本身不出现横向滚动条。

## 稳定：界面不要忽上忽下

- 会出现又消失的内容（任务、通知、计数）先给它固定的位置：区块常驻、空时一行写「无」，而不是插入再移除。
- 很快结束的东西不必显示（例如 1.5 秒内结束的后台命令）；显示过的条目结束后原位停留几秒再离开。
- 一直在变的数字用等宽数字和固定最小宽度，秒数跳动时文字不挤动。
- 异步内容先占好高度（骨架或预留行），加载完成后不推开下面的内容。

## 动效与可访问性

- 动效只用在一个有意义的时刻（进入、完成、切换），时长 150–250ms，用 `cubic-bezier(.22,1,.36,1)` 这类缓出曲线；`prefers-reduced-motion` 时关闭。
- 正文对比度至少 4.5:1，图标与大号文字 3:1；颜色不是唯一的信息载体（图表直接标数值，状态有文字）。
- 每个可点击元素有可见的 `:focus-visible`，触控目标不小于 32px。

## 避开模板味

用户没有指定风格时，不要落到这些常见套路上：米白底配衬线标题和赤陶色；近黑底配单一荧光绿；紫蓝渐变首屏；emoji 当小标题；所有内容居中；每个块都是同样的大圆角加大阴影。用户点名要其中某种风格时照做。

## 交付前自检

1. 375px 与 1280px 宽度：主操作可达，没有横向滚动，文字没被截断。
2. 浅色与深色各看一遍：没有只在一种主题下可读的颜色，`body` 有明确的背景色。
3. 最长的真实文案、空状态、加载中、出错各看一次。
4. 键盘 Tab 一遍：焦点顺序合理、可见。
5. 把看到的问题记下来再改，不靠猜。

### 可运行示例

用浏览器打开 [变量与组件示例](examples/visual-tokens.html)：一套完整的明暗变量、字号阶梯、按钮层级和一行稳定的状态条。右上角切换浅色、深色和跟随系统，确认每个组件在两种主题下都可读。复用时先替换变量的值，不改组件规则。
